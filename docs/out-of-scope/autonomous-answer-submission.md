# Autonomous Answer submission

The human submits the authoritative Answer. Question Chat may explain, read
bounded repository evidence and append a server-validated proposed option. It
cannot select, submit, cancel, expire or otherwise resolve the Question. Proposed
options do not change a human's current selection or unblock the owner by themselves.

Keeping advice separate from decision authority preserves the reason the coding
agent requested human input. The normal Answer path retains concurrency checks
and first-terminal-transition behavior; Chat has no shell or mutation tools.
